# Permissions
- 0-iam_betty: switches the current user to betty
- 1-who_am_i: prints the effective username of the current user
- 2-groups: prints all the groups the current user is part of
- 3-new_owner: changes the owner of the file hello to betty
- 4-empty: creates an empty file called hello
- 5-execute: adds execute permission to the owner of hello
- 6-multiple_permissions: adds execute to owner and group, read to others
- 7-everybody: adds execute permission to everybody
- 8-James_Bond: sets no permissions for owner and group, all for others
- 9-John_Doe: sets the mode of hello to -rwxr-x-wx
- 10-mirror_permissions: copies the permissions of olleh to hello
- 11-directories_permissions: adds execute to all subdirectories for everyone
- 12-directory_permissions: creates my_dir with permissions 751
- 13-change_group: changes the group of hello to school
- 14-change_owner_and_group: sets owner vincent and group staff for all files
- 15-symbolic_link_permissions: changes owner and group of the link _hello
- 16-if_only: changes owner of hello to betty only if owned by guillaume
